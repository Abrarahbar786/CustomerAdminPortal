# CustomerAdminPortal

A professional Customer Management Portal built using ASP.NET Core MVC, C#, Entity Framework Core, and SQL Server. The application provides a dashboard to manage customer records and a REST API for customer operations.

## Features

- Admin Login and Authentication
- Dashboard with customer statistics
- Create, Read, Update, and Delete (CRUD) operations
- Customer search and pagination
- Form validation
- Delete confirmation
- RESTful API for customer management
- SQL Server database integration
- Responsive UI using Bootstrap

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript, Bootstrap, Razor Views
- **Backend:** C#, ASP.NET Core MVC, ASP.NET Core Web API
- **Database:** Microsoft SQL Server
- **ORM:** Entity Framework Core
- **Authentication:** ASP.NET Core Identity
- **Tools:** Visual Studio, Git, GitHub, Postman

## Getting Started

1. Clone or download this repository.
2. Open the solution in Visual Studio.
3. Configure the SQL Server connection string using .NET User Secrets.
4. Ensure the required database and migrations are configured.
5. Run the application from Visual Studio.

**Important:** Never commit actual database passwords, admin passwords, or other secrets to a public repository.

## API

The customer API is available at:

`/api/customer`

Use Postman to test the supported customer API operations.

## Project Purpose

This project was developed as a hands-on learning project to practice ASP.NET Core MVC, REST API development, database integration, authentication, and CRUD operations.
